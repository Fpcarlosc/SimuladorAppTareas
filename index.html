Entiende las dos direcciones

La UI envía eventos; el UiState devuelve los datos que se representan.

south

UI → ViewModel

Los callbacks reciben el dato nuevo y llaman a un método del ViewModel. Ejemplo:

onValueChange = {
    tareaViewModel.actualizarTitulo(it)
}
north

ViewModel → UI

El ViewModel publica un nuevo estado. Compose lo recoge y vuelve a dibujar los elementos que leen ese estado:

val uIState by
    tareaViewModel.tareaUIState
        .collectAsState()

value = uIState.tarea.titulo
Ver el método insertarTarea() explicado
_tareaUIState.update { estadoActual ->
    estadoActual.copy(
        tarea = Tarea(),
        listaTareas = estadoActual.listaTareas + estadoActual.tarea
    )
}

Al pulsar Insertar, el ViewModel añade la tarea que estaba en edición a listaTareas y sustituye tarea por una tarea vacía. El flujo emite un estado nuevo con la lista ampliada y el formulario reiniciado.
